# 演示数据说明

文件：`accounting_transactions_demo.csv`

- 来源：加拿大政府 Open Government Portal，Receiver General Accounting Transactions
- 原始下载地址：https://donnees-data.tpsgc-pwgsc.gc.ca/ba1/tcrg-rgat/tcrg-rgat.csv
- 许可：数据集页面标注为加拿大政府开放数据，可按其开放数据许可复用；正式对外发布前请保留来源与许可说明。
- 本地样本：从原始 CSV 取前 500 行，并将字段整理为英文机器字段名；没有加入个人姓名、客户联系方式或银行卡号等个人敏感字段。
- 适用演示：按日期、部门、借贷方向和金额做交易汇总，演示费用、现金流和预警逻辑。
- 限制：这是政府会计交易数据，不代表普通企业销售数据；营业收入、客户、产品、预算等模块仍需后续企业样例数据或人工构造的模拟数据。

## 爬取数据 -> 导入格式（`accounting_transactions_import.csv`）

由 `scripts/adapter_rgat_to_import.py` 从 `data/raw/receiver_general_accounting_transactions.csv`
确定性转换而来，字段已改成平台导入模板的中文列名，可直接用于「数据导入」页面或接口。

- 规模：8909 行，覆盖 2026-04 ~ 2026-10，52 个部门，340 个科目。
- 映射：
  - `交易日期` ← `Accounting-Effective-Date`
  - `收入金额` ← CR（贷方）金额；`费用金额` ← DR（借方）金额
  - `科目名称` ← 总账科目 > 明细科目 > 财务编码块（逐级回退）；`科目编码` ← 总账科目代码
  - `摘要` ← 财务编码块 + 部门 + 凭证类型 + 控制号，保证每行可回溯到源记录
- 校验：适配后「收入合计 + 费用合计」与源文件金额合计**分毫对平**（5,911,694,977,878.44）。
- **已知限制（重要，不要当成经营结论解读）**：
  - 源文件没有「成本 / 主营业务成本」科目，因此 `成本金额` 一律为 0，全部支出都落在 `费用金额`。
  - 源数据没有银行流水时间轴，`现金流入 / 现金流出` 一律留 0，不用发生额冒充现金流。
  - 这些是政府部门的预算支出（DR）与冲销（CR），**必然呈现巨额「净利为负」**，
    所以每个期间都只触发「利润异常」预警，不触发「成本率异常」。它适合用来验证
    「导入 -> 指标 -> 预警 -> 看板」的管道正确性，不能反映企业盈利能力。
  - 金额量级极大且分布极不均（单行 0.09 ~ 38,779,133,491.80，7~9 月每月约 1 万亿元），
    主要是部门 097 的 `JVBDP`（公共债务）与部门 006 的 `JVRDI` 等真实公共账目凭证，
    不是解析错误；因此看板上的数字会远超常规企业量级，解读时必须带上这个背景。
  - 最后一个期间 2026-10 只有 93 行（源文件截到 2026-10-02），趋势图末点会明显偏低。
